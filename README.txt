MEERA & ARJUN — MIDNIGHT HEIRLOOM WEDDING WEBSITE

DESIGN DIRECTION
Inspired by the supplied midnight-blue and gold invitation reference:
- Deep midnight navy / ink-blue invitation palette.
- Antique gold foil-style ornamental frame and corner flourishes.
- Gold monogram-style detailing and delicate hanging gold motifs.
- Rich navy hero panel with a refined rectangular invitation-card composition.
- Warm ivory supporting sections to keep long-form content readable.
- Responsive mobile and desktop layout.

FILES
- index.html — invitation sections and colour settings panel
- css/style.css — Midnight Heirloom theme and responsive styling
- js/script.js — countdown, RSVP demo, QR code, scroll reveal and colour customiser

RUN LOCALLY
1. Extract this ZIP.
2. Open the wedding_site folder in Visual Studio Code.
3. Open index.html using Live Server.

CUSTOM COLOURS
- Midnight Heirloom is the default palette.
- Other palettes remain available: Royal Ivory, Emerald Palace and Midnight Blue.
- Click Customize to choose a palette or adjust primary, accent and background colours.
- Save selection stores custom colours in this browser.
- Reset colours returns to Midnight Heirloom.

UPDATE WEDDING DETAILS
Edit index.html to change names, family names, date, timings, venue, address and RSVP deadline.
Update the countdown date in js/script.js. Format:
new Date("YYYY-MM-DDTHH:MM:SS+05:30")

IMPORTANT
- Names, family details, date and venue are sample content; replace them before publishing.
- RSVP currently shows a local thank-you message only; it does not send or store responses.
- The QR code encodes the current page URL. Upload the website and use its final public URL before printing the QR code.
- Google Fonts and QRCode.js are loaded from CDNs and need an internet connection.
